# Сито — клієнтська частина програмного забезпечення розпізнавання фейкових повідомлень у месенджерах

Навчальний проєкт із дисципліни «Розробник фронтенду програмних систем» (Київський національний університет імені Тараса Шевченка).

## 1. Призначення проєкту

«Сито» — односторінковий клієнтський вебзастосунок (SPA), призначений для перевірки підозрілих текстових повідомлень із месенджерів (Telegram, Viber, WhatsApp, Signal, SMS), перегляду знайдених ознак маніпуляції чи фішингу, ручного коригування вердикту, ведення локального журналу перевірок, обліку відомих відправників та експорту даних у форматах CSV і JSON.

Основні розділи застосунку:
1. **Перевірка (`/check`)** — форма введення повідомлення та панель результату зі скінченним автоматом на 7 станів, швидким підвантаженням шаблонів і живою звіркою відправника з реєстром.
2. **Журнал (`/history` та `/history/:id`)** — історія перевірок із комбінованою фільтрацією за вердиктом, месенджером, ознакою маніпуляції та текстовим пошуком, експортом CSV/JSON і переглядом пов'язаних записів.
3. **Зведення (`/overview`)** — аналітичні зрізи за журналом і реєстром відправників, розподіл за джерелами та матриця спрацювань ознак із прямими переходами до відповідних вибірок.
4. **Відправники (`/senders`)** — локальний реєстр відправників («У чорному списку», «Під наглядом», «Довірений») із підрахунком повідомлень кожного контакту в журналі та швидким переходом до перевірки повідомлення від обраного контакту.
5. **Довідник і шаблони (`/rules`)** — каталог 6 евристичних правил детекції з ваговими коефіцієнтами та бібліотека демонстраційних шаблонів повідомлень із завантаженням у форму перевірки в один клік.

Особливості реалізації:
- Проєкт містить клієнтську частину (фронтенд). Робота з даними реалізована через клієнтський сервіс (`src/services/mockApi.ts`) та локальні сховища браузера (`sessionStorage`, `localStorage`).
- Усі початкові записи в журналі перевірок, реєстрі відправників, шаблонах та обліковому записі є тестовими даними (`test data`).

## 2. Технологічний стек

- **Мова програмування:** TypeScript 5 (`strict: true`)
- **Бібліотека інтерфейсу:** React 18.3
- **Маршрутизація:** React Router 6.28
- **Керування станом:** React Context + `useReducer` (`AuthContext`, `ChecksContext`, `SendersContext`, `analysisReducer`)
- **Стилізація:** CSS Modules + CSS Custom Properties (`src/styles/tokens.css`), локальні шрифти IBM Plex Sans та IBM Plex Mono (`@fontsource`)
- **Збирання:** Vite 5 + PostCSS (`autoprefixer`) + генерація заголовка `Content-Security-Policy` для production-збірки
- **Тестування та якість коду:** Vitest, `@testing-library/react`, `jsdom`, `@vitest/coverage-v8`, ESLint 9, Prettier

## 3. Вимоги до середовища та запуск

Перевірене середовище: Node.js 20+ LTS / 24.x, npm.

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev

# Запуск юніт- та інтеграційних тестів
npm test

# Перевірка покриття коду тестами
npm run coverage

# Перевірка лінтером ESLint
npm run lint

# Збирання production-версії у каталог dist/
npm run build
```

